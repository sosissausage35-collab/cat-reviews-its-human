# cat-reviews-its-human

One funny one-star review written by a house cat about its human owner —
an entry for the make.fun bounty **"Make the AI Judge Laugh: Cat Reviews
Its Human"**.

## Run

```sh
node main.ts
```

This writes the review to `/output/entry.txt` (one line, 111 characters,
deterministic — byte-identical on every run).
